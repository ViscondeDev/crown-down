## The Game

Crown Down is a turn-based puzzle game inspired by chess.

You play as a pawn who can choose to move as a **Rook, Bishop, or Knight** each turn. Every level introduces a different board layout, requiring the player to find the correct sequence of moves to eliminate every royal piece.

**Platform:** HTML5 · **Input:** Mouse / Touch
